# eMudhra HSM dice

This is a W8 (8 sided dice or octaeder) that contains all of the private keys leaked in the eMudhra incident. 
It is not a fair dice. Because of the manufacturing process, the bed-adjacent and top walls are thicker than the other walls, making the dice slightly cooked.

The STL was created by ChatGPT.

## Printing instructions

I had success printing this with standard PLA filament on a Prusa Core One +, using the "0.15 mm FAST DETAIL" preset. No ironing. The more infill you use, the nicer the dice feels. 

Filament type: PLA
Layer height: .15mm ("0.15 mm FAST DETAIL" preset on Prusa Slicer)
Ironing: Optional
Infill: Try 50%
